# Hub Technicien EuroMed

Hub mobile-first pour les techniciens EuroMed, pensé pour une utilisation iPhone.

## Navigation
- **Accueil** : outils terrain + aperçu des cinq maintenances.
- **Maintenance** : page dédiée avec onglets pour les cinq équipements.
- **Documentation** : accès direct à `https://hawaryou.github.io/envoi_pdf_euromed/`.
