# Hub Technicien EuroMed

Version mobile du Hub Technicien EuroMed, pensée pour iPhone et inspirée des interfaces d'applications mobiles modernes : cartes colorées, grandes zones tactiles, navigation flottante et défilement horizontal.

## Déploiement GitHub Pages
1. Décompresser le ZIP.
2. Mettre le contenu du dossier `euromed-hub-iphone-v2` à la racine du dépôt GitHub.
3. Activer GitHub Pages sur la branche souhaitée.

Les liens des outils et des cinq maintenances sont déjà configurés dans `index.html`.
